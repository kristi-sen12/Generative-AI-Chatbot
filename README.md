## 🤖 AI Chatbot Using LangChain, Groq API & Streamlit

### 📌 Project Overview
Developed and deployed an interactive AI-powered chatbot using **LangChain, Groq API, and Streamlit**. The chatbot enables users to have natural, context-aware conversations with an AI assistant. By implementing session state management and conversation history, it retains previous interactions and uses them as context to generate relevant responses and maintain conversational continuity.

### 🌐 Live Demo
The application is deployed on **Streamlit Community Cloud**.

🔗 **Live Application:** https://generative-ai-personal-chatbot.streamlit.app/

### 🚀 Features
- **AI-Powered Conversations:** Generates intelligent responses using Groq API.
- **LangChain Integration:** Manages LLM interactions and conversational workflows.
- **Streamlit Interface:** Provides an interactive and user-friendly chat interface.
- **Session State Management:** Maintains conversation data during an active session.
- **Conversation History:** Stores previous user messages and AI responses.
- **Context-Aware Responses:** Uses previous conversation context to answer follow-up questions.
- **Cloud Deployment:** Deployed and accessible online through Streamlit Community Cloud.

### 🛠️ Technologies Used
- Python
- LangChain
- Groq API
- Streamlit
- Large Language Models (LLMs)
- Session State Management
- Streamlit Community Cloud

### ⚙️ How It Works
1. Users interact with the chatbot through the Streamlit interface.
2. User messages are processed using LangChain.
3. Previous conversation history is retrieved from Streamlit session state.
4. The conversation context is passed to the LLM through the Groq API.
5. The LLM generates a response based on the current query and previous conversation.
6. Both user messages and AI responses are stored in session state for subsequent interactions.
